# Code Review Finding Template

Use one entry per actionable, evidence-based finding. Keep recommendations concise; include code only when necessary to explain the issue.

## [Finding title]
- **Severity:** Critical / High / Medium / Low
- **Location:** `path/to/file` (line number)
- **Evidence:** What in the changed code causes the issue
- **Impact:** Concrete consequence
- **Recommendation:** Minimal direction to resolve

If no actionable findings are identified, say so and state any relevant review limitations. Do not pad the report with speculative suggestions.
